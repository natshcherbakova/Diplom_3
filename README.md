## Задание 3: UI-автотесты

### Автотесты для проверки веб-приложения Stellar Burgers

«Stellar Burgers» — учебный веб-сервис для заказа бургеров.

### Реализованные сценарии

Созданы UI-автотесты на Selenium с использованием паттерна Page Object. 
Все тесты запускаются в двух браузерах: Google Chrome и Mozilla Firefox. Драйвер создаёт фабрика `DriverFactory` в `conftest.py`, браузер выбирается параметром командной строки `--browser`.

Тестовые данные создаются перед тестом и удаляются после него: пользователь и заказ создаются через API.

Покрытые сценарии:

**Восстановление пароля**
  * переход на страницу восстановления пароля по ссылке «Восстановить пароль»
  * ввод email и клик по кнопке «Восстановить»
  * клик по иконке показать/скрыть пароль подсвечивает поле
**Личный кабинет**
  * переход по клику на «Личный кабинет»
  * переход в раздел «История заказов»
  * выход из аккаунта
**Основной функционал (конструктор)**
  * переход по клику на «Конструктор»
  * переход по клику на «Лента заказов»
  * клик по ингредиенту открывает всплывающее окно с деталями
  * всплывающее окно закрывается кликом по крестику
  * при добавлении ингредиента в заказ увеличивается его счётчик
  * залогиненный пользователь может оформить заказ
**Лента заказов**
  * клик по заказу открывает всплывающее окно с деталями
  * заказы пользователя из «Истории заказов» отображаются в «Ленте заказов»
  * при создании нового заказа увеличиваются счётчики «Выполнено за всё время» и «Выполнено за сегодня»
  * после оформления заказа его номер появляется в разделе «В работе»

Всего 19 сценариев в каждом браузере (38 запусков). Все тесты проходят успешно. Отчёт Allure: `allure_report/index.html`

### Структура проекта

- `page_objects` - пакет с Page Object, по классу на каждую страницу:
  - `base_page.py` - класс `BasePage` - общие методы: ожидания, клики, ввод текста, переходы по шапке сайта
  - `main_page.py` - класс `MainPage` - главная страница (конструктор бургеров)
  - `auth_page.py` - класс `AuthPage` - страница авторизации
  - `forgot_password_page.py` - класс `ForgotPasswordPage` - страницы восстановления и сброса пароля
  - `profile_page.py` - класс `ProfilePage` - личный кабинет и история заказов
  - `orders_feed_page.py` - класс `OrdersFeedPage` - лента заказов
- `locators` - пакет с локаторами, по файлу на каждую страницу
- `helpers` - вспомогательные модули для работы с API:
  - `endpoints.py` - адреса API-ручек
  - `methods.py` - создание и удаление пользователя, создание заказа
- `conftest.py` - фабрика драйверов, параметры `--browser` и `--headless`, фикстуры: браузер, объекты страниц, тестовый пользователь, заказ, предусловия
- `data.py` - генерация данных пользователя, названия и ID ингредиентов, email для восстановления пароля
- `urls.py` - адреса страниц приложения
- `requirements.txt` — зависимости проекта и их версии
- `allure_report` - HTML-отчёт Allure
- `tests` - каталог с тестами:
  - `test_forgot_password.py` - класс `TestForgotPassword` - с тестами
  - `test_personal_account.py` - класс `TestPersonalAccount` - с тестами
  - `test_constructor.py` - класс `TestConstructor` - с тестами
  - `test_orders_feed.py` - класс `TestOrdersFeed` - с тестами

### Запуск автотестов

Для запуска нужны установленные браузеры Google Chrome и Mozilla Firefox. Команды выполняются из корня проекта.

Установка зависимостей:

```bash
> `$ pip install -r requirements.txt`
```

Запуск автотестов в обоих браузерах и сохранение результатов для отчёта:

```bash
pytest --alluredir=allure_results
```

Запуск в одном браузере (`chrome`, `firefox` или `all` - оба, по умолчанию):

```bash
pytest --browser firefox --alluredir=allure_results
```

Запуск без окна браузера (headless):

```bash
pytest --browser chrome --headless --alluredir=allure_results
```

Для генерации статического отчёта:

```bash
allure generate allure_results -o allure_report --clean
```

Просмотр отчёта:

```bash
allure open allure_report
```
